The Two Courses

Designed for students with a wide range of computer experience. No prior coding is assumed. The second course builds directly on the first.

Web Page Design

Introductory

Internet and web concepts, file management, keyboarding, the web design process, color theory, graphics, HTML, CSS, hyperlinks, tables, and responsive web design.

Tools
Visual Studio Code, Adobe Photoshop, Typing.com, MyCareerTech
Culminating work
A career portfolio website, published to the school network, plus a career-preparation unit (resume, cover letter, interview practice).

Web Application Development

Advanced Capstone

Terminal, Git, and GitHub; advanced Photoshop and CSS; foundational JavaScript, Canvas, and interactive design; AI-assisted coding; individual and team projects; Career Skills Challenge preparation.

Tools
VS Code, Terminal, Git and GitHub, Netlify or Cloudflare, Photoshop, approved AI tools
Culminating work
An online career portfolio and an AI-assisted application that addresses a local business or community need.

Year 1 Web Page Design → Year 2 Web Application Development

How Skills Progress

Students learn to do the work by hand first, so they can judge, direct, and fix what AI tools produce.

  1. Build the foundation

    Typing, file and folder organization, visual design, then hand-coded HTML and CSS. Students write the code themselves.

  2. Work like a developer

    Terminal, Git and GitHub, JavaScript with visible results, Canvas graphics, and publishing live to the web.

  3. Direct and evaluate AI

    Students break a problem into requirements, prompt AI tools, then test, debug, and modify the result for a real business or community need.

How the Classes Run

  • Industry software, not simulations. Students use the same tools professionals use: VS Code, Git and GitHub, Photoshop, Netlify, and approved AI tools.
  • No textbook. Learning comes from demonstrations, hands-on practice, Google Classroom, and teacher-built interactive labs and apps.
  • Career readiness built in. Both courses include keyboarding, professional habits, MyCareerTech lessons, resumes, and portfolio review.
  • Resubmission is allowed. Students can resubmit work multiple times for an improved grade.
  • Responsible AI. AI output is not assumed correct. Students are responsible for reviewing, testing, and modifying it and for understanding the work they submit.
  • Online publishing is permissioned. Students publish online only with a signed Online Publishing/AI Permission Form on file.

Results

Career Skills Challenge: 22 top-three finishes, including 8 first-place finishes, across the 2012–2013 through 2025–2026 competition years. Most recently, 1st, 2nd, and 3rd place in 2025–2026. The pathway did not compete in 2019–2022, or the competition was cancelled.
