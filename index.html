Web Page Design and Web Application Development offer a hands-on pathway from digital foundations to creating and publishing web applications. Students build skills in file management, visual design, HTML, and CSS, then expand into JavaScript interactivity, version control, and AI-assisted development. Through projects that reflect their interests, students learn to plan, build, test, refine, and publish their work with attention to accessibility and usability. Coursework connects practical skills with California Information and Communication Technologies standards, Arts, Media, and Entertainment standards, and career readiness, while evolving to reflect changes in industry tools and practices.

This site brings the pathway together in one place: course outlines and the syllabus, interactive labs and games for students, the tools teachers use to run the classroom, and the career technical education standards behind the work.
